## 📌 Project Overview

**Nova Creator AI** is an AI-powered web application that generates **cinematic and viral captions for reels, edits, and short-form videos**.

Users simply type a short description of their video, and the system instantly generates engaging captions using **Amazon Nova Lite AI via Amazon Bedrock**.

This project demonstrates how **AI models can be integrated into real-world applications** to help content creators save time and boost creativity.

---

## 🎯 Features

* 🤖 **AI Caption Generation** – Generate captions using Amazon Nova Lite
* 🎬 **Perfect for Creators** – Ideal for reels, edits, and cinematic videos
* 📥 **Download Captions** – Save generated captions instantly
* 📋 **Copy Captions** – Copy captions directly for social media
* ⚡ **Fast Processing** – Real-time AI response
* 🎨 **Modern UI** – Clean and responsive website design

---

## 🧠 How It Works

1. User enters a **short description of their video**
2. Request is sent to the **Spring Boot backend API**
3. Backend communicates with **Amazon Bedrock**
4. **Amazon Nova Lite AI model** generates captions
5. Captions are returned and displayed on the website
