# 🚀 Nova Creator AI

AI-powered Instagram caption generator built using **Amazon Nova AI via AWS Bedrock**.

Nova Creator AI helps content creators instantly generate engaging captions for **Instagram reels, movie edits, and cinematic videos** with emojis and hashtags.

---

# 📌 Problem

Content creators often spend a lot of time thinking about the perfect caption for their social media posts.
Creating captions that are engaging, creative, and include relevant hashtags can be difficult and time-consuming.

---

# 💡 Solution

**Nova Creator AI** solves this problem by using **Amazon Nova Lite** to automatically generate captions from simple prompts.

Users can enter prompts such as:

• Movie captions
• Travel reels captions
• Motivational captions

The AI instantly generates multiple creative captions complete with emojis and hashtags.

---

# ⚙️ Features

✨ AI-powered caption generation
✨ Instagram-ready captions with emojis
✨ Hashtag optimized captions
✨ Copy captions instantly
✨ Download captions option
✨ Simple and clean user interface

---

# 🧠 How It Works

1. User enters a caption prompt
2. Backend sends request to **Amazon Nova Lite through AWS Bedrock**
3. Nova AI generates multiple captions
4. Results are displayed instantly on the website
